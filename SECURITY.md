# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| main | Yes |

## Report a vulnerability

Open this repository's **Security** tab, select **Report a vulnerability**, and submit a private GitHub security advisory. Include the affected commit, reproduction steps, impact and any suggested fix. Redact live credentials and private data.

Keep vulnerability details out of public issues and pull requests. Coordinate disclosure with the maintainers through the advisory.

Repository maintainers must enable private vulnerability reporting in **Settings → Code security → Private vulnerability reporting** before accepting reports through this path.
